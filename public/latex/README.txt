SwiftLaTeX pdfTeX WebAssembly engine: https://github.com/SwiftLaTeX/SwiftLaTeX
Release v20022022, GPL-3.0 (see LICENSE).
The worker has a local-package override for swiftlatexpdftex.fmt to reduce startup network latency.
Format file from https://texlive.texlyre.org/pdftex/10/swiftlatexpdftex.fmt (TeX Live distribution).
Other TeX packages are downloaded on demand from https://texlive.texlyre.org/.
Source code for the upstream engine is available at the GitHub URL above.
